### 실행 컨텍스트

실행할 코드에 제공할 환경 정보들을 모아놓은 객체

```jsx
var a = 1;
function outer() {
    function inner() {
        console.log(a);
        var a = 3;
    }
    inner();
    console.log(a);
}

outer();
console.log(a);
```

실행 컨텍스트와 콜스택

콜스택 내부 : 전역 컨텍스트 → outer → inner → outer → 전역 컨텍스트

### inner 객체의 내부

- VariableEnvironment
- LexicalEnvironment
- ThisBinding

### VariableEnvironment

현재 컨텍스트 내의 식별자들에 대한 정보와 외부 환경의 정보를 포함한다.

VariableEnvironment에 담기는 내용은 LexicalEnvironment와 같음, 최초 실행 시 **스냅샷** 유지

실행 컨텍스트를 생성할 때 VariableEnvironment에 먼저 정보 담고 → 복사해서 LexicalEnvironment를 생성, 그 후엔 LexicalEnvironment 사용

### LexicalEnvironment

정적 환경

- LexicalEnvironment의 수집자료
    - environmentRecord
        - environmentRecord와 호이스팅
            
            저장 : 현재 컨텍스트와 관련된 코드의 식별자 정보
            
            식별자 : 매개변수 식별자, 함수 자체, var 변수 등
            
            → 자바스크립트 엔진은 코드 실행되기 전임에도 불구하고 코드의 변수명을 모두 알고 있음 (최상단으로 끌어올린 다음 실제 코드를 실행한다)
            
            - 호이스팅 예시 1
            
            ```jsx
            function a(x) {
                console.log(x);
                var x;
                console.log(x);
                var x = 2
                console.log(x);
            }
            a(1)
            
            // 매개변수 할당
            function a() {
            		var x = 1;
                console.log(x);
                **var x;**
                console.log(x);
                var x = 2;
                console.log(x)  ;
            }
            
            a()
            
            ////////////////////////////////////////
            // 호이스팅 마친 상태
            
            function a() {
                var x;
                var x;
                var x;
            
                x = 1;
                console.log(x);
                console.log(x);
                x = 2;
                console.log(x);
            }
            
            // 결과 : 1, 1, 2
            ```
            
            - 호이스팅 예시 2
            
            ```jsx
            function a() {
                console.log(b);
                var b = 'bbb';
                console.log(b);
                function b() {}
                console.log(b);
            }
            
            a();
            
            ////////////////////////////////////////
            // 호이스팅 마친 상태
            function a() {
                var b;
                function b() {}
            
                console.log(b);
                b = 'bbb';
                console.log(b);
                console.log(b);
            }
            
            a();
            // 결과 : function b, 'bbb', 'bbb'
            ```
            
            - 호이스팅 예시 3 (함수 선언문/표현식)
            
            ```jsx
            console.log(sum(1, 2));
            console.log(multiply(3, 4));
            
            function sum(a, b) { // 함수 선언문
                return a + b;
            }
            
            var multiply = function (a, b) { // 함수 표현식
                return a * b;
            };
            
            ////////////////////////////////////////
            // 호이스팅 마친 상태
            var sum = function sum(a, b) {
                return a + b;
            };
            var multiply; // 변수는 선언부만 끌어올림
            
            console.log(sum(1, 2));
            console.log(multiply(3, 4)); // 답1 
            
            multiply = function (a, b) {
                return a * b;
            };
            
            // 결론 : 함수 표현식이 조금 더 안전하다
            ```
            
            - 답1
                
                multiply is not a function
                
                이유 : var multiply는 undefined, undefined(3,4)는 function이 아님
                
    - outerEnvironmentReference
        - 스코프, 스코프 체인
            
            스코프 : 식별자에 대한 유효범위
            
            스코프 체인 : 식별자의 유효범위를 안에서 바깥으로 검색해나가는 것
            
            이를 가능하게 하는 것이 outerEnvironmentReference
            
            ```jsx
            var a = 1;
            var outer = function () {
                var inner = function () { // 함수 표현식
                    console.log(a);
                    var a = 3
                }
                inner()
                console.log(a);
            }
            outer()
            console.log(a);
            ```
            
            1. 전역 컨텍스트가 활성화, 전역 컨텍스트의 environmentRecord에  {a, outer} 식별자 저장, outerEnvironmentReference는 아무것도 안담김
            2. 변수 a에 1을, outer에 함수를 할당
            3. outer() 호출
            4. outer 실행 컨텍스트의 environmentRecord에 inner 식별자 저장, outerEnvironmentReference는 outer함수가 선언될 때의 **LexicalEnvironment**가 담김, {global, {a, outer}}
            5. inner에 함수 할당
            6. inner 실행 컨텍스트의 environmentRecord에 a식별자 저장 
                
                outerEnviromentReference는 inner함수가 선언될 때의 **LexicalEnvironment**가 담김, `[outer, {inner}]` 를 참조복사함
                
            7. console.log(a) : inner컨텍스트의 environmentRecord에 a 검색 / 없어서 undefined
            8. 변수 a에 3 할당
            9. inner함수 종료, inner 실행컨텍스트가 콜스택에서 제거 + outer 활성화됨
            10. console.log(a) a에 접근, 실행 컨텍스트의 LexicalEnvironment에 접근해서 environmentRecord에 a가 있으면 넘기고/ 없으면 outerEnvironmentReference의 environmentRecord로 넘어감 ⇒ a가 전역에 있음
            11. outer함수 종료, 콜스택에서 제거 / 전역 컨텍스트 활성화
            12. console.log(a), 현재 활성상태인 전역 컨텍스트의 environmentRecord에 a를 검색함
            
- 참고 함수 선언문과 함수 표현식
    
    ```jsx
    function a() {} // 함수 **선언식**
    a();
    
    var b = function () {} // 익명 **함수표현**
    b();
    
    var c = function d() {} // **함수표현식**
    c(); // OK
    d()l // Error!
    ```
    

### 전역변수와 지역변수

전역 공간에서 선언한 변수 : 전역 변수

함수 내부에서 선언한 변수 : 지역변수

## 정리

실행 컨텍스트 객체는 활성화되는 시점에 VariableEnvironment, LexicalEnvironment, ThisBinding 세 가지 정보를 수집함

VariableEnvironment, LexicalEnvironment가 동일한 내용으로 구성되지만, 

LexicalEnvironment는 함수 함수 실행 도중에 변경 사항 즉시 반영

VariableEnvironment는 초기 상태 유지

LexicalEnvironment : environmentRecord(매개변수명, 변수의 식별자, 함수명 등을 수집) + outerEnvironmentReference(바로 직전의 LexicalEnvironment 정보를 참조)
