## 컴퓨터 시스템

- 소프트웨어

  정보처리 종류와 그 수행시간을 지정해주는 Command의 집합

- 하드웨어

  CPU(중앙처리장치), 기억장치, 입출력장치, Power, Fan …

소프트웨어는 하드웨어에 의존적이다.

컴퓨터의 수행속도는 근본적으로 하드웨어에 달려있고, 소프트웨어의 질에 따라 하드웨어의 사용 효율이 더 향상될 수 있다.

## 1.1 컴퓨터의 기본 구조

컴퓨터는 프로그램 코드를 정해진 순서대로 실행한다. 컴퓨터는 필요한 데이터를 Read, Processing, Store한다.

![](/assets/img/2026-01-03/be-cs-computer-system-overview-1.png)

### **컴퓨터의 기본 구조**

- CPU
  - 프로그램 실행 및 데이터 처리
- 기억장치
  - 주 기억장치
  - 보조 기억 장치

| **주 기억장치** | **보조기억장치** |
| --- | --- |
| 빠른 액세스 | 느린 액세스 |
| 가격이 비쌈 | 가격이 저렴함 |
| 저장능력: 휘발성 | 저장능력: 영구 |

- 입출력 장치
  - 각 장치마다 있는 별도의 제어장치에 의해 동작, Client와 컴퓨터 간 소통을 위한 도구

## 1.2 정보의 표현과 저장

- 컴퓨터가 처리하는 정보의 종류
  - Code
  - Data

  이는 Bit의 조합으로 표현한다.

### **언어**

고급언어 - 사람에게 편한 언어

컴파일러 - 고급 언어를 기계어로 변환해주는 소프트웨어

기계어 - 기계가 이해할 수 있는 언어

어셈블리 언어 - 고급 언어를 기계어로 바꿔주는 중간 언어

### **고급언어 → 기계어로의 번역 과정**

예) Z = X + Y

**어셈블리 프로그램**

1. LOAD A, X : 기억장치 X번지 값을 레지스터 A에 적재
2. ADD A, Y : 기억장치 Y번지 값을 A와 더한 후 A에 적재
3. STOR Z, A : A의 내용을 기억장치 Z번지에 저장

(LOAD, ADD, STOR을 니모닉스라고 부름)

**기계어 프로그램**

1. 001/00101
2. 100/00110
3. 010/00111

(opcode 명령/operand 주소)

## 1.3 시스템의 구성

CPU와 기억장치 및 I/O 장치의 상호작용을 분석하고, 컴퓨터시스템의 구성방법 및 동작 원리에 관한 주제

### CPU와 기억장치의 접속

![](/assets/img/2026-01-03/be-cs-computer-system-overview-2.png)

- 시스템 버스 - CPU와 시스템 내의 다른 요소들 사이에 정보를 교환하는 통로
  - 주소 버스 - CPU가 외부로 발생하는 주소 정보를 전송하는 신호의 집합
  - 데이터 버스 - CPU가 기억장치 혹은 I/O 장치 사이에 데이터를 전송하기 위한 신호들의 집합
  - 제어 버스 - CPU가 시스템 내의 각종 요소들의 동작 제어에 필요한 신호 선들의 집합
