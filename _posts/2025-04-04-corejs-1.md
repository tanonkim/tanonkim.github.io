### 데이터 타입 :

- 기본형 : number, string, boolean, null, undefined, symbol
- 참조형 : array, function, date, regexp, map, set

### 식별자와 변수

변수 : 변할 수 있는 무언가(데이터)

식별자 : 변수명, 즉 데이터를 식별하는데 사용하는 이름

### 변수 선언


```javascript
var a; // 변수 선언
a = 'abc' // 변수에 데이터 할당

var a = 'abc' // 변수 선언 + 데이터 할당
```

| 변수영역 | 주소 | … | 1002 | 1003 | 1004 |
| --- | --- | --- | --- | --- | --- |
|  | 데이터 |  |  | 이름 a
값 : @5004 |  |
| 데이터 영역 | 주소 | 5002 | 5003 | 5004 |  |
|  | 데이터 |  |  | ‘abc’ |  |

변수와 데이터를 별도의 공간에 나누어 저장하는게 최적

### 불변값

변수, 상수를 구분짓는 변경 가능성의 대상은 변수 영역 메모리

```javascript
var b = 5;
var c = 5;
b = 7; // 5와 7은 변경할 수 없음(불변성)
```

### 가변값

```javascript
var ojb1 = {
	a : 1;
	b : 'bbb'
}
```

| 변수영역 | 주소 | … | 1002 | 1003 | 1004 |
| --- | --- | --- | --- | --- | --- |
|  | 데이터 |  |  | 이름 :  obj1
값 : @5004 |  |
| 데이터 영역 | 주소 | 5001 | 5002 | 5003 | 5004 |
|  | 데이터 | @7103 ~ ? |  | 1 | ‘bbb’ |

| 객체 @5001의 변수 영역 | 주소 | … | 7103 | 7104 | 7105 |

값 : @5003 | 이름 : b

차이점 : **객체의 변수 영역(프로퍼티)이 별도로 존재**

```javascript
var ojb1 = {
	a : 1;
	b : 'bbb'
}

ojb1.a = 2 // 이러면 새로운 객체가 만들어지는게 아니라 객체 내부의 값만 변함
```



### 변수 복사 비교

```javascript
var a = 10;
var b = a;

var obj1 = {c : 10, d : 'ddd'};
var obj2 = obj1;
```

![](/assets/img/corejs/1/2.png)

<br>


만약 아래처럼 객체의 프로퍼티 값이 변경된다면?

```javascript
var a = 10;
var b = a;

var obj1 = {c : 10, d : 'ddd'};
var obj2 = obj1;

b = 15; // 값을 @5001 -> @5004로 변경
obj2.c = 20; // @7103의 값만 변경되지, 1003/1004는 변경되지 않음
```

```javascript
a !== b 
obj1 === obj2 // 참조형은 한 단계를 더 거치게 됨
```

### 불변 객체

React, Vue 등 매우 중요한 기초가 되는 개념, 기존의 데이터가 변하지는 않음

원본 객체가 변해야 하지 않는 경우가 필요함.

```javascript
var user ={
    name : 'TANON',
    gender : 'male'
}

var changeName = function (user, newName) { // 객체의 가변성 예시
    var newUser = user;
    newUser.name = newName;
    return newUser;
}

var user2 = changeName(user, 'KIHYEON');

if (user !== user2) {
    console.log('유저 정보가 변경되었습니다.');
}

console.log(user.name, user2.name); // **KIHYEON** KIHYEON
console.log(user === user2); // true

```

수정된 코드

```javascript
var user ={
    name : 'TANON',
    gender : 'male'
}

var changeName = function (user, newName) {
    return {
        name : newName,
        gender : user.gender
    }    
}

var user2 = changeName(user, 'KIHYEON');

if (user !== user2) {
    console.log('유저 정보가 변경되었습니다.');
}

console.log(user.name, user2.name); // TANON KIHYEON
console.log(user === user2); // false

```

- 얕은 복사(기존 정보 복사해서 새로운 객체 반환)

```javascript
var copyObject = function (target) {
    var result = {};
    for (var prop in target) {
        result[prop] = target[prop];
    }
    return result;
}

var user2 = copyObject(user);
user2.name = 'KIHYEON'

// user !== user2
```

### 얕은 복사/깊은 복사

얕은 복사 : 바로 아래 단계의 값만 복사

깊은 복사 : 내부의 모든 값을 하나하나 찾아서 복사

- 객체의 프로퍼티 중에서 기본형 데이터인 경우에는 그대로 복사
- 참조형 데이터는 다시 그 내부의 프로퍼티들을 복사
- [structuredClone()으로 깊은 복사하기](https://www.notion.so/structuredClone-1cc588b624798049ae31fe38bebc1658?pvs=21)

객체의 깊은 복사를 수행하는 범용 함수

```javascript
var copyObjectDeep = function (target) {
    var result = {}
    if (typeof target ==='object' && target !== null) {
            for (var prop in target) {
         result[prop] = copyObjectDeep(target[prop]) // 재귀 호출
    }
    } else  {
        result = target;
    }
    return result
}
```

### undefined, null

undefined

값을 대입하지 않은 변수 (데이터 영역의 메모리 주소를 지정하지 않은 식별자에 접근)

객체 내부의 존재하지 않는 프로퍼티에 접근

return 문이 없거나 호출되지 않는 함수의 실행 결과

```javascript
var obj= {a : 1};
console.log(obj.a); // 1
console.log(obj.b); // undefined

var func = funciton {}
var c = func()

console.log(c) // undefined
```
