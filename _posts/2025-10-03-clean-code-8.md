코드로 표현하지 못한 부분을 보완하기 위해 주석을 사용한다.

오늘 날에는 좋은 이름을 선택하지 못했을 때 주석을 많이 사용한다.

### 주석 처리된 코드 제거하기

문제 : 주석 처리된 코드가 있다

→ 그대로 두지 말고 소스 버전 관리 시스템(git)을 이용해 코드를 제거하기

### 더 이상 사용하지 않는 주석 제거하기

문제 : 더 이상 정확하지 않은 주석이 있다

→ 더 이상 사용하지 않는 주석은 제거하기

### 게터 주석 제거하기

문제 : 사소한 주석이 달린 게터가 있다.

→ 게터를 사용하지 말기. 게터나 사소한 기능에 대해서는 주석을 달지 말기

```javascript
contract Property {
	int private price;
	
	function getPrice public view returns(int) {
			/* Price 반환 */
		return price;
	}
}
```

```javascript
contract Property {
	int private _price;
	
	function price() public view returns(int) {
		return _price;
	}
}
```

### 메서드 내부 주석 제거하기

문제 : 메서드 내부에 주석이 있습니다.

→ 메서드 내부에 주석 추가하지 말기

### 주석을 테스트로 대체하기

문제 : 함수가 수행하는 작업을 설명하는 주석이 있는데, 정적이로 오래된 설명 대신 동적이고 잘 유지 관리되는 문서화를 원한다.

→ 주석을 가져와서 함축시켜 이를 함수명으로 사용하기. 코드를 테스트 한 뒤 주석을 제거
