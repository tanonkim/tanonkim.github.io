⇒ ES6에서 클래스 문법이 추가됨

음식 : superclass

과일 : subclass

### section2 자바스크립트의 클래스

생성자 함수 Array를 new 연산자와 함께 호출하면 인스턴스가 생성됨

이때 Array를 일종의 클래스라고 한다면, Array의 프로토타입 객체 내부 요소들이 인스턴스에 상속됨

Array 내부 프로퍼티들 중 prototype 프로퍼티를 제외한 나머지 인스턴스에 상속되지 않음

인스턴스에 상속되는지 여부에 따라 스태틱 멤버, 인스턴스 멤버(프로토타입 메서드)로 나뉨

예) `스태틱` 메서드, `프로토타입` 메서드

```jsx
// 생성자
var Rectangle = function (width, height) {
    this.width = width;
    this.height = height;
};

// 프로토타입 메서드
**Rectangle.prototype.getArea** = function () {
    return this.height * this.width;
};

// 스태틱 메서드
**Rectangle.isRectangle** = function (instance) {
    return instance instanceof Rectangle && 
	    instance.width > 0 && instance.height > 0;
};

var rect1 = new Rectangle(3, 4);
console.log(rect1.getArea()); // 12 // rect1.__proto__.getArea
console.log(rect1.isRectangle(rect1)); // Uncaught TypeError : not a function
console.log(Rectangle.isRectangle(rect1)); // true
```

1. rect1.getArea() : rect1.__proto__.getArea()
    
    프로토타입 메서드 : 인스턴스에서 직접 호출할 수 있는 메서드
    
2. rect1.isRectangle(rect1)
    
    rect1.__proto__, rect1.__proto__.__proto__에도 없음
    
    `스태틱 메서드` : 인스턴스에서 직접 접근할 수 없는 메서드
    

### section3 클래스 상속

### 3.1 기본 구현

클래스 상속은 객체지향에서 중요한 요소 중 하나

예) Grade 생성자 함수 및 인스턴스

```jsx
var Grade = function () {
    var args = Array.prototype.slice.call(arguments);
    for (var i = 0; i < args.length; i++) {
        this[i] = args[i];
    }
    this.length = args.length;
};

Grade.prototype = [];
var g = new Grade(100, 80);
console.log(g);
```

예) 문제점

```jsx
g.push(90);
console.log(g); // Array { '0': 100, '1': 80, '2': 90, length: 3 }

delete g.length;
g.push(70);
console.log(g); // Array { '0': 70, '1': 80, '2': 90, **length: 1** }
```

Grade 클래스의 인스턴스는 배열 메서드를 상속하지만, 일반 객체의 성질을 그대로 지니므로 삭제가 가능함 ⇒ 문제가 됨

g.__proto__ === Grade.prototype이 빈 배열을 가리키고 있는게 문제임

**결론 : 클래스에 있는 값이 인스턴스의 동작에 영향을 줘서는 안됨**

### 3.2 클래스가 구체적인 데이터를 지니지 않게 하는 방법

**클래스가 구체적인 데이터를 지니지 않게** 하는 방법 중 가장 쉬운 방법 : 

인스턴스를 생성하고 나서 프로퍼티를 지우고, 더는 새로운 프로퍼티를 추가할 수 없게 하는 것

예1) 인스턴스 생성 후 프로퍼티 제거

```jsx
delete Sauare.prototype.width;
delete Square.prototype.height;
**Object**.**freeze**(Square.prototype)
```

```jsx
var extendClass = function (SuperClass, SubClass, subMethods) {
    SubClass.prototype = new SuperClass();
    for (var prop in SubClass.prototype) {
        if (SubClass.prototype.hasOwnProperty(prop)) {
            delete SubClass.prototype[prop];
        }
    }
    if (subMethods) {
        for (var method in subMethods) {
            SubClass.prototype[method] = subMethods[method];
        }
    }
    **Object.freeze(SubClass.prototype);**
    return SubClass;
};

var Square = extendClass(Rectangle, function (width) {
    Rectangle.call(this, width, width);
});
```

예2.1) 빈 생성자 함수 생성

1. 빈 생성자 함수를 생성해서
2. 그 prototype이 SuperClass의 prototype을 바라보게 한 다음
3. SubClass의 prototype에는 Bridge 인스턴스를 할당하게 하는 것

```jsx
var Rectangle = function (width, height) {
	this.width = width;
	this.height = height;
}
Rectangle.prototype.getArea = function () {
	return this.width * this.height;
}

var Square = function (width) {
	Rectangle.call(this, width, width);
}

var Bridge = function () {}; // 1. 빈 생성자 함수 생성
Bridge.prototype = Rectangle.prototype; // 2. SuperClass의 prototype을 바라보게 한 다음
Square.prototype = new Bridge(); // SubClass의 prototype에 Bridge 인스턴스 할당
Object.freeze(Square.prototype);
```

예2.2) 빈 생성자 함수 생성

```jsx
var extendedClass2 = (function () {
	var Bridge = function () {} // 빈 생성자 함수 생성
	return function (SuperClass, SubClass, subMethods) {
		Bridge.prototype = SuperClass.prototype; // Superclass의 prototype을 바라보게 한 다음
		SubClass.prototype = new Bridge(); // SubClass의 prototype에 Bridge 인스턴스를 할당하게 하는 것

		if (subMethods) {
			for (var method in subMethods) {
				SubClass.prototype[method] = subMethods[method];
			}
		}
		Object.freeze(SubClass.prototype);
		return SubClass;
	}
})();
```

예3) Object.create 활용

```jsx
Square.prototype = Object.create(Rectangle.prototype);
Object.freeze(Square.prototype);
```

### 3.3 Constructor 복구하기

3가지 방법으로 기본적인 상속은 성공했지만, SubClass 인스턴스의 constructor는 여전히 SuperClass를 가리키는 상태이다. (Subclass 인스턴스에는 constructor가 없고, Subclass.prototype에도 없다.) SuperClass만 출력될 뿐이다.

⇒ SubClass.prototype.constructor가 원래의 SubClass를 바라보면 된다.

예3.1) 인스턴스 생성 후 프로퍼티 제거

```jsx
var extendClass1 = function (SuperClass, SubClass, subMethods) {
	SubClass.prototype = new SuperClass();
	for (var prop in SubClass.prototype) {
		if (SubClass.prototype.hasOwnProperty(prop)) {
			delete SubClass.prototype[prop]
		}
	}
	SubClass.prototype.constructor = SubClass;
	if (subMethods) {
		for (var method in subMethods) {
			SubClass.prototype[method] = subMethods[method];
		}
	}
	Object.freeze(SubClass.prototype);
	return SubClass;
}
```

예3.2) 빈 함수를 활용

```jsx
var extendedClass2 = (function () {
	var Bridge = function () {} // 빈 생성자 함수 생성
	return function (SuperClass, SubClass, subMethods) {
		Bridge.prototype = SuperClass.prototype; // Superclass의 prototype을 바라보게 한 다음
		SubClass.prototype = new Bridge(); // SubClass의 prototype에 Bridge 인스턴스를 할당하게 하는 것
		SubClass.prototype.constructor = SubClass;

		if (subMethods) {
			for (var method in subMethods) {
				SubClass.prototype[method] = subMethods[method];
			}
		}
		Object.freeze(SubClass.prototype);
		return SubClass;
	}
})();
```

예3.3) Object.create 활용

```jsx
var extendedClass3 = function (SuperClass, SubClass, subMethods) {
	SubClass.prototype = Object.create(SubClass.prototype);
	SubClass.prototype.constructor = SubClass;
	if (subMethods) {
		for (var method in subMethods) {
			SubClass.prototype[method] = subMethods[method];
		}
	}
	Object.freeze(SubClass.prototype);

	return SubClass;
}
```

### section4 ES6의 클래스 및 클래스 상속

![](/assets/img/2025-03-25/image.webp)

생성자 함수 Array를 new 연산자와 함께 호출하면 instance가 생성된다. 이 때 Array를 클래스라고 한다면 prototype의 객체 내부 요소들이 instance에 상속(정확하게는 프로토타입 체이닝에 의한 참조)된다.

instance가 참조하는지 여부에 따라 `static` member와 `instance` member로 나뉜다. 

prototype 내부에 있는 메서드는 instance가 호출 가능, prototype에 없는 메서드는 instance가 참조하지 않으므로 호출 불가능하다 ⇒ instance에 직접 접근할 수 없는 메서드를 `스태틱 메서드`라고 한다.

**ES5와 ES6의 클래스 문법 비교**

```jsx
var ES5 = function (name) {
	this.name = name;
}

ES5.staticMethod = function () {
	console.log(this.name); // ES5
	
	return this.name + ' staticMethod'
}

ES5.prototype.method = function () {
	return this.name + ' method'
}

var es5Instance = new ES5('es5');
console.log(ES5.staticMethod()); // ES5 staticMethod 
console.log(es5Instance.method()); // es5 method
```

```jsx
var ES6 = class {
	constructor (name) {
		this.name = name;
	}

	static staticMethod () {
		return this.name + ' static method';
	}
	method() {
		return this.name + ' method';
	}
}

var es6Instance = new ES6('es6');
console.log(ES6.staticMethod()); // ES6 static method
console.log(es6Instance.method()); // es6 method
```

**ES6의 클래스 상속**

```jsx
var Rectangle = class {
	constructor (width, height) {
		this.width = width;
		this.height = height;
	}
	getArea () {
		return this.width * this.height;
	}

var Square = class extends Rectangle {
	constructor (width) {
		**super(width, width); // 부모 클래스 생성자 호출**

		console.log('size is : ' , super.getArea()); // super : Rectangle(부모 클래스)의 getArea() 호춞
	}
}

const test = new Square(12);

test.getArea()
```
