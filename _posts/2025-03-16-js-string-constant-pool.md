## V8 Engine이 string과 number값을 다루는 방법

### Constant pool을 통한 메모리 절약

Node.js에선 node 명령어로 bytecode에 대한 출력을 확인할 수 있는 옵션을 제공함

```javascript
node --print-bytecode --print-bytecode-filter='test*' index.js > bytecode.txt
```

### 문자열 상수 풀

JS는 String Constant Pool에서 문자열 메모리를 관리한다. 만약 이미 메모리에 할당된 문자열이 있다면 새 변수에 문자열을 할당하더라도 메모리를 새로 생성하지 않고 주소값을 반환한다.

```javascript
let str1 = "Hello";
let str2 = "Hello";

console.log(`str1 === str2 : ${str1 === str2}`);

let str3 = new String("Hello");

console.log(`str1 == str3 : ${str1 == str3}`);
console.log(`str1 === str3 : ${str1 === str3}`);

// str1 === str2 : true
// str1 == str3 : true
// str1 === str3 : false

```

`===`는 주소값과 자료형까지 검사함.

new String(””)으로 생성자를 사용해 객체를 생성하면 다른 주소값을 가진 문자열 리터럴이 됨

```javascript
// temp.js

function stringTest1() {
   let str1 = 'this is string';
   let str2 = 'this is string';
}

function stringTest2() {
    let str1 = 'this is string';
    let str2 = new String('this is string');
}

stringTest1();
stringTest2();

// node --print-bytecode --print-bytecode-filter='stringTest*' temp.js > string_code.txt
```

bytecode를 살펴보면 두 함수에서 모두 Constant Pool에 `this is string`  문자열을 1회씩 할당함

해당 문자열은 런타임동안 변경되지 않는 리터럴 상수이므로 Constant Pool에 할당됨

그리고 동일한 값을 갖기에 중복 선언되지 않고 Constant Pool에 1개만 할당됨

![](/assets/img/2025-03-16/js-string-constant-pool-1.png)

stringTest1에서는 변수 str1, str2는 동일한 constant pool의 메모리 공간을 참조함

![](/assets/img/2025-03-16/js-string-constant-pool-2.png)

stringTest2에서는 객체 str2의 heap 영역에 할당되지만, 변수 str1에서 **constant pool**의 메모리 공간을 참조함

### Number

V8 Engine은 숫자에 대해서도 중복 할당을 최적화 한다.

숫자 데이터는 SMI(SMall Integer) 여부에 따라 두 종류로 나뉘며 최적화 방법이 다르다.

SMI는 32bit 환경에서는 31bit 부호있는 정수값을 의미하고, 64bit 환경에서는 32bit 부호있는 정수값을 의미한다.

- 32비트 : SMI 범위: `(2^30)` ~ `(2^30 - 1)` (약 `1,073,741,824` ~ `1,073,741,823`)
- 64비트 : SMI 범위: `(2^31)` ~ `(2^31 - 1)` (약 `2,147,483,648` ~ `2,147,483,647`)

예)

```javascript
function numberTest1() {
    let num1 = 111111111111111111;
    let num2 = 111111111111111111;
}

function numberTest2() {
    let num1 = 12345;
    let num2 = 12345;
}

function numberTest3() {
    let num1 = 1.1;
    let num2 = 1.1;
}

numberTest1();
numberTest2();
numberTest3();
```
