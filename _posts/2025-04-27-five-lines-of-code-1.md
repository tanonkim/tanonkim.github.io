코드 스멜과 단위 테스트를 가지고 리팩터링을 학습하는 방법은 진입장벽이 높다.

### 1.1 리팩토링이란

기능을 변경하지 않고 코드를 변경하는 것

리팩토링을 해야 하는 이유

- 코드를 더 빠르게 만들기 위해
- 더 작은 코드를 만들기 위해
- 코드를 더 일반적이거나 재사용 가능하게 하기 위해
- 코드의 가독성을 높이고 유지보수를 용이하게 하기 위해

리팩터링의 유형은 객체지향 프로그래밍 언어를 사용하는 작업에 크게 의존함

### 1.2 스킬 : 무엇을 리팩터링할 것인가

코드 스멜은 코드가 나쁘다는 것을 암시하는 것

코드 스멜 : 심오한 문제를 일으킬 가능성이 있는 프로그램 소스코드의 특징

### 1.3 문화 : 리팩터링은 언제 할까?

정기적으로 수행하는 것이 효과적, 비용이 덜 듦 ⇒ 일상 업무에 통합하는 것이 좋음

1.3.2 명확한 기준이 필요하다

DRY, **KISS** : 한번 찾아보기!!

DRY : DRY : Don’t Repeat Yourself

KISS : KISS : Keep it Simple, Stupid

### 1.4 도구 : 안전한 리팩터링 방법

레시피처럼 상세하고 단계별로 구조화된 리팩터링 패턴

버전 관리

컴파일러

### 1.5 시작하는데 필요한 도구

객체지향 언어
