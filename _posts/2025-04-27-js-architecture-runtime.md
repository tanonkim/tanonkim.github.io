## 런타임

런타임은 프로그램의 실행이 시작되어 종료될 때까지의 시간동안 **프로그램이 동작하는 모든 단계와 상황**을 말한다.

### 런타임 환경

프로그램이 실행되는 동안 필요한 모든 요소와 리소스를 포함한 환경을 말한다.

런타임 환경은 여러가지 기능을 제공하는데, 주로 아래와 같은 역할을 한다.

1. 메모리 관리

   프로그램이 사용하는 메모리를 관리하고, 할당/해제하는 역할을 한다.

2. 변수/데이터 관리

   런타임은 변수의 scope를 관리하고, 데이터의 타입을 체크하며, 메모리 내에서 데이터를 저장하고 조작하는 등의 역할을 수행한다.

3. 예외처리

   프로그램 실행 중에 발생하는 예외나 오류사항을 처리하고, 프로그램이 충돌하지 않도록 안정성을 제공한다.

4. 동시성관리

   멀티쓰레딩과 같은 병렬 실행을 관리하고, 쓰레드(프로세스 내에서 실행되는 여러 흐름 단위)/프로세스(실행중인 프로그램)간의 동기화를 제어하여 동시성 문제를 해결한다.

5. 입출력관리

   파일, 네트워크, 입출력 장치 등과의 상호작용을 관리하고 제어한다.

6. 라이브러리 지원

   프로그램이 라이브러리를 호출하고 사용할 수 있도록 환경을 제공한다.

7. 가상화/추상화

   하드웨어 추상화와 가상화를 통해 프로그램이 특정 하드웨어와 운영체제에 종속되지 않도록 한다.

### 웹브라우저

웹브라우저는 자바스크립트의 대표적인 런타임 환경으로, 웹페이지의 자바스크립트 코드를 실행한다.

대표적인 엔진은 구글 : V8, 애플 : JavaScriptCore이 존재한다.

DOM에  접근하여 웹페이지의 구조와 컨텐츠를 조작할 수 있다.

브라우저와 이벤트처리, AJAX 요청, 그리고 웹 API 호출 등을 지원한다.

### Node

서버에서 동작하는 자바스크립트 런타임 환경이다. 브라우저 외부에서 자바스크립트 코드를 실행할 수 있게 해준다.

구글 V8을 기반으로 동작한다.

비동기 I/O와 이벤트 루프 기능을 구현하기 위해 **libuv**를 사용한다.

npm을 패키지 관리자로 이용한다.
